# AWS Developer: Local Secondary Indexes (LSIs) by Jeff Kessie


## What is a Local Secondary Index (LSI)?

It’s an index we define that shares the table's partition key but uses an alternate sort key for scans and queries. It must be created at table creation time you cannot add, remove, or modify it later. All queries based on that sort key are significantly faster using the index than the main table.
